Firebase 설정 방법:

  1. Firebase Console (console.firebase.google.com) 접속
  2. 새 프로젝트 생성 또는 기존 프로젝트 선택
  3. 프로젝트 설정 > 웹 앱 추가
  4. Firebase SDK 구성 정보 복사
  5. Realtime Database 생성 (테스트 모드로 시작)
  6. 아래에 설정 정보 입력 후 "연결하기" 클릭
