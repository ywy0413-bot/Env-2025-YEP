📱 참여자 접속 방법
====================================

1단계: 파일 다운로드
--------------------
아래 링크를 클릭하세요:

https://raw.githubusercontent.com/ywy0413-bot/Env-2025-YEP/claude/real-time-scoring-011CUPJMiAah3Q3oeU9uDzci/realtime-scoring-final-1761192734.html

- PC: Ctrl + S 눌러서 저장
- 모바일: 브라우저 메뉴 → "다운로드" 또는 "저장"


2단계: 파일 열기
--------------------
다운로드한 파일을 더블클릭하여 열기


3단계: 참여자 모드 선택
--------------------
화면에 3개 버튼이 보이면:
"참여자 모드" 버튼 클릭


4단계: 이름 입력
--------------------
본인 이름 입력


5단계: 점수 투표
--------------------
1. 현재 곡 확인
2. 1~10점 중 선택
3. "투표하기" 버튼 클릭


✅ 주의사항
--------------------
- 한 곡당 1번만 투표 가능
- 이름은 정확히 입력 (중복 투표 방지)
- 참가자 이름은 보이지 않음 (공정한 평가를 위해)


❓ 문제 해결
--------------------
Q: "대기 중" 메시지만 보임
A: 관리자가 아직 곡을 설정하지 않았습니다. 잠시 기다려주세요.

Q: "이미 투표했습니다" 메시지
A: 같은 이름으로 이미 투표했습니다. 다른 곡을 기다려주세요.

Q: 파일이 열리지 않음
A: 크롬, 엣지, 파이어폭스 등 최신 브라우저 사용


🎉 즐거운 행사 되세요!
