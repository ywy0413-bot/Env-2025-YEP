===========================================
실시간 점수 집계 시스템 사용 방법
===========================================

방법 1: GitHub에서 다운로드
--------------------------
1. 브라우저에서 다음 주소 열기:
   https://github.com/ywy0413-bot/Env-2025-YEP

2. 현재 브랜치를 다음으로 변경:
   claude/real-time-scoring-011CUPJMiAah3Q3oeU9uDzci

3. realtime-scoring.html 파일 클릭

4. 'Raw' 버튼 클릭

5. Ctrl+S 눌러 파일 저장

6. 저장한 파일을 더블클릭하여 브라우저에서 열기


방법 2: 아래 파일 내용 복사
--------------------------
1. Windows: 메모장 열기
   Mac: TextEdit 열기
   Linux: gedit 또는 텍스트 에디터 열기

2. 아래 전체 내용 복사

3. 메모장/에디터에 붙여넣기

4. 다른 이름으로 저장:
   - 파일명: realtime-scoring.html
   - 파일 형식: 모든 파일 (*.*) 선택
   - 인코딩: UTF-8

5. 저장한 파일을 더블클릭
